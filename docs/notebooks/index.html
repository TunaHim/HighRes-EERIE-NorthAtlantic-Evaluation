Notebooks

Every analysis step as an executed notebook. Each opens with a plain-language explanation of its terms, has a note above every code cell and a caption under every figure, and ends with findings, limitations and open questions. Start with 00.

To rerun them: clone the repository, create the conda environment from environment.yml, download the regional data with python -m eerie_uk.download and run scripts/build_all.ps1. Step-by-step instructions are in the README.
